# Connectra: Your Connected Life

An independent third-party assistance platform for exploring internet, TV, cable and streaming options. Built as a client-side single-page application with React, TanStack Router, and Tailwind CSS.

## Development

Requires [Bun](https://bun.sh).

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
bun run preview
```

The build outputs a static SPA to `dist/` — deploy it behind any static host with SPA fallback routing (all paths served `index.html`).
